# CERVORUS INTERNATIONAL — Portfolio

Static HTML/CSS/JS portfolio. No build command is required.

## Netlify
1. Unzip this folder.
2. Open Netlify Drop: https://app.netlify.com/drop
3. Drag the `CERVORUS_FINAL` folder into the drop zone.
4. Netlify will publish the site and provide a `netlify.app` URL.

Keep `index.html`, `style.css`, `script.js`, and `assets/` together.
